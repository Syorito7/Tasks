Папка содержит 12 лабораторных работ на языке Си, охватывающих темы от базовых типов данных до более сложных задач:

- Типы данных
- Работа с файлами (потоками)
- Создание и управление двухсвязными списками

Каждая лабораторная работа направлена на поэтапное освоение и закрепление ключевых концепций языка C.

# Инструкция по запуску Dockerfile

## Сборка Docker-образа

Перейдите в папку с Dockerfile и выполните команду:

```bash
docker build -t all-labs .
```


Важные замечания по лабораторным работам
В 11-й лабораторной работе не хватает необходимого заголовочного файла (header).

В 12-й лабораторной работе отсутствует CMake-файл для сборки.

Пожалуйста, учитывайте эти моменты при работе с лабораторными.
